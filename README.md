# Color Bar Timer — デジタルカラーバータイマー

スマートフォン（iPhone/Android）、タブレット、パソコンで動く、無料のカラーバータイマーです。
HTML / CSS / JavaScriptだけで作られており、インストールやサーバー契約は不要です。

## 主な機能

- 30本のバーが、設定した時間の経過に合わせて**1本ずつ消える**
- 例：30分設定 → 1分ごとに1本、60分設定 → 2分ごとに1本
- 開始時は青、経過25%で緑、50%で黄、75%で赤
- 終了時には**30本のバーを再表示し、赤と透明を交互に点滅**させる
- 残り時間を大きく表示（1秒単位）
- 任意の時間・分・秒を設定（1秒〜99時間59分59秒）
- 5/15/25/30/45/60/90分のクイック設定
- スタート / ストップ（一時停止） / 再開 / リセット
- ページを再読み込みしても、計測中のタイマーを復元
- ホーム画面への追加（PWA）・キャッシュ済みならオフライン起動も可能
- 外部ライブラリ・広告・アカウント登録なし

## ブラウザーで試す（PC）

`index.html` をダブルクリックすると、基本的なタイマー機能が動きます。
※ PWA（ホーム画面追加やオフラインキャッシュ）の検証には、GitHub PagesなどHTTPSのホスティングが必要です。

## GitHub Pagesへ無料で公開する

1. [GitHubの新規リポジトリ作成](https://github.com/new)を開く。
2. リポジトリ名を `color-bar-timer` とする（任意）。**Public** で作成する。
3. GitHubの「Add file」→「Upload files」で、このフォルダの中身をアップロードする（**ZIPファイルそのものではなく、展開後のファイル**）。`assets/` フォルダも維持する。`index.html` はリポジトリの最上位に置く。
4. 「Commit changes」で保存する。
5. リポジトリの「Settings」→「Pages」を開く。
6. 「Build and deployment」の「Source」に `Deploy from a branch` を指定する。
7. `main`、`/(root)` を選択して「Save」。
8. GitHub Pagesの公開処理が完了すると、`https://ユーザー名.github.io/color-bar-timer/` のようなURLが表示される。

公開にかかる費用はGitHub Freeの公開リポジトリなら0円です。公開URLは誰でも開けるため、個人情報は入れないでください。

## iPhone / iPadのホーム画面に追加する

1. Safariで公開URLを開く。
2. 共有メニューを開いて「ホーム画面に追加」を選択。
3. 「Webアプリとして開く」があればオンにして「追加」。
4. ホーム画面の「カラーバー」のアイコンから起動できます。

iPhoneとiPadでは同じURLを使えますが、**タイマーの設定や進行状態はデバイス間で自動同期されません**。

## 仕組み

表示本数は `ceil(残り時間 / 設定時間 × 30)` （0〜30本）。
画面の描画処理は200msごとに更新しますが、残り時間は実際の時計と終了予定時刻との差で計算するため、非表示タブでタイマー処理が遅延しても、復帰時に経過時間へ追いつきます。

カウントダウン中は、対応ブラウザーで画面スリープの抑制を試みます。

**重要**：アプリを閉じたり画面をロックした場合、終了時にバックグラウンドで点滅や通知を出すことは保証できません。再度開いたときに終了状態を表示します。終了時に確実な音・通知が必要な用途には、端末標準の時計・アラームを併用してください。

## ファイル構成

- `index.html` — 画面の構造
- `style.css` — レスポンシブな画面デザイン
- `app.js` — タイマー・バーの色・保存処理
- `manifest.webmanifest` — ホーム画面追加用設定
- `sw.js` — オフライン利用のためのキャッシュ処理
- `assets/` — アイコン画像
- `.nojekyll` — GitHub Pages用

## 補足

- ストップは**一時停止**です。再開は「再開」を押してください。
- リセットを押すと、現在の設定時間で最初から準備します。
- 時間の入力を変更できるのは「準備完了」状態のときだけです。進行中・一時停止中・終了後は一度リセットしてください。
- PCではスペースキーで開始・停止・再開、Rキーでリセット（入力欄やボタンにフォーカスしている場合を除く）。
- 設定情報はブラウザーの `localStorage` に保存され、外部サーバーへは送信されません。
- オフライン利用は一度オンラインで読み込み、Service Workerのキャッシュが作成された後に利用できます。
